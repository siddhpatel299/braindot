# Screenshots

Drop real screenshots of the running app here (not mockups — the README links
these directly and reviewers compare them against the live demo).

Expected files, referenced from the root README:

| file | what to capture |
|---|---|
| `editor.png`     | A note open in the editor: file tree, tags, some prose, the AI context panel |
| `graph.png`      | The knowledge graph with a decent number of connected nodes |

Capture at a wide window (roughly 1600px) so text stays legible when GitHub
scales the image down.
